# Creative Stom — premium dental clinic demo (Tashkent)

Production demo built from a client design brief. Follow the spec exactly — do not invent visual style, and do not invent facts (prices, names, doctor bios, license data). Unknown specifics stay as literal `[bracketed]` placeholders in the content files. The only sanctioned exception: demo patient reviews, which are clearly marked `// TODO demo-content`.

## Stack

Next.js (App Router, TypeScript) + Tailwind CSS v4 (CSS-based theme, no `tailwind.config.js`). No UI kits. Animation via the `motion` package (Framer Motion successor).

## Design tokens

Defined in `src/app/globals.css` as CSS vars, mapped into Tailwind via `@theme inline` (utilities: `bg-navy`, `text-ivory`, `border-gold`, etc.).

| Token | Hex | Tailwind utility | Role |
|---|---|---|---|
| navy | `#0B1D2E` | `navy` | deep ink navy — hero, dark sections |
| navy2 | `#16324A` | `navy-2` | slate navy — elevated dark surfaces |
| ivory | `#FAF8F4` | `ivory` | warm porcelain — page background |
| bone | `#EFEAE0` | `bone` | soft bone — alternating light sections |
| gold | `#D4AF6A` | `gold` | champagne — accents, CTAs |
| goldDark | `#9A7B44` | `gold-dark` | deep bronze — accent on light surfaces |
| ink | `#2A3642` | `ink` | graphite body text |
| muted | `#7C8894` | `muted` | cool mist — micro-labels only |
| line | `#DFD8C8` | `line` | warm greige hairline borders |

Do not add new colors. If a section seems to need one, it doesn't — reuse a token.

Contrast rules (measured):
- `text-gold-dark` on light surfaces is ~3.7:1 — use only for eyebrows, rules, tags, and hover states; small always-visible links on light use `text-navy`/`text-ink` with `hover:text-gold-dark`.
- `text-muted` on ivory is ~3.4:1 — only for uppercase micro-labels at `text-xs` or smaller; body copy uses `text-ink` or `text-ink/80`.
- On navy surfaces, borders use `border-ivory/10..15` (no dedicated dark hairline token).

## Fonts

- `--font-display` → Playfair Display (headings only)
- `--font-body` → Inter (everything else)
- Both loaded via `next/font/google`, subsets `["latin", "cyrillic"]`, `display: "swap"`.

## Motion

- App is wrapped in `<LazyMotion features={domMax} strict>` (`src/components/MotionProvider.tsx`) — always import `{ m }` from `"motion/react"` and use `m.div` etc.; `motion.div` throws under `strict`.
- Reduced motion is handled globally by `<MotionConfig reducedMotion="user">`; scroll-linked effects must also no-op via `useReducedMotion` where transforms would break content.
- Shared primitives live in `src/components/motion/`: `RevealGroup`/`RevealItem` (staggers), `Parallax`, `AnimatedCounter`, `TextReveal`, `Marquee`, `ReviewsCarousel`. Site-wide `Reveal` is `src/components/Reveal.tsx`.
- Discipline: one orchestrated entrance per view; scroll-linked choreography is reserved for hero, manifesto, section-scrubbed rules, and image parallax. Don't scatter micro-animations.

## Layout rules

- Sections: `py-24 md:py-32`.
- Container: `max-w-[1240px]` (use the shared `<Container>` component).
- `SectionHeading` is the site's **only** decorative motif: left-aligned eyebrow (Inter 600, uppercase, tracking-wide, goldDark on light backgrounds / gold on navy backgrounds) + a 2px gold rule + a Playfair heading. Don't invent a second motif.
- No two adjacent sections may share a layout pattern (alternate backgrounds, grid shapes, image placement, etc.).

## Content rule

**All visible text comes from the content layer** — no component hardcodes copy: not a label, not a placeholder string, not an alt text. The content layer is:

- `src/content/types.ts` — master `SiteContent` interface; enforces UZ/RU parity at compile time.
- `src/content/uz/*.ts` + `src/content/ru/*.ts` — per-locale dictionaries, composed in each locale's `index.ts`.
- `src/config/site.config.ts` — locale-independent facts (phone, socials, coordinates, stats) and feature flags.
- `src/content/media.ts` — every image path used by components.

If new copy is needed, add it to `types.ts` + both locale dicts first (with a `// TODO` if it's a bracketed placeholder), then consume it via `getContent(locale)`.

## Forbidden

- Gradients
- Glassmorphism / blur panels
- Emoji
- Identical soft-shadow card grids repeated across sections
- Centered section titles (headings are left-aligned, per `SectionHeading`)
- Icon rows (no generic icon-set decoration)
- Round-avatar testimonial carousels
- New colors outside the token table above

## Placeholders

Generated by `scripts/gen-placeholders.mjs` into `public/placeholders/` (local SVGs only — no external image services). Regenerate with `npm run placeholders`. Every image path referenced from components must come from `src/content/media.ts`.

## Testing

Test every feature at 390px, 768px, and 1440px viewport widths before considering it done.

## Workflow

After each feature: run `npm run dev`, verify in the browser at the three breakpoints above, then `git commit`.
