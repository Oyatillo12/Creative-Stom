# Creative Stom — premium dental clinic demo (Tashkent)

Production demo built from a client design brief. Follow the spec exactly — do not invent visual style, and do not invent facts (prices, names, testimonials). Unknown specifics stay as literal `[bracketed]` placeholders sourced from `src/content/site.ts`.

## Stack

Next.js (App Router, TypeScript) + Tailwind CSS v4 (CSS-based theme, no `tailwind.config.js`). No UI kits.

## Design tokens

Defined in `src/app/globals.css` as CSS vars, mapped into Tailwind via `@theme inline` (utilities: `bg-navy`, `text-ivory`, `border-gold`, etc.).

| Token | Hex | Tailwind utility |
|---|---|---|
| navy | `#10263B` | `navy` |
| navy2 | `#1B3650` | `navy-2` |
| ivory | `#F5F2EC` | `ivory` |
| gold | `#C19A5B` | `gold` |
| goldDark | `#8A6A38` | `gold-dark` |
| ink | `#33404D` | `ink` |
| muted | `#6B7683` | `muted` |
| line | `#DDD6C9` | `line` |

Do not add new colors. If a section seems to need one, it doesn't — reuse a token.

## Fonts

- `--font-display` → Playfair Display (headings only)
- `--font-body` → Inter (everything else)
- Both loaded via `next/font/google`, subsets `["latin", "cyrillic"]`, `display: "swap"`.

## Layout rules

- Sections: `py-24 md:py-32`.
- Container: `max-w-[1240px]` (use the shared `<Container>` component).
- `SectionHeading` is the site's **only** decorative motif: left-aligned eyebrow (Inter 600, uppercase, tracking-wide, goldDark on light backgrounds / gold on navy backgrounds) + a 2px gold rule + a Playfair heading. Don't invent a second motif.
- No two adjacent sections may share a layout pattern (alternate backgrounds, grid shapes, image placement, etc.).

## Content rule

**All visible text comes from `src/content/site.ts`.** No component hardcodes copy — not a label, not a placeholder string, not an alt text. If new copy is needed, add it to `site.ts` first (with a `// TODO` if it's a bracketed placeholder), then consume it.

## Forbidden

- Gradients
- Glassmorphism / blur panels
- Emoji
- Identical soft-shadow card grids repeated across sections
- Centered section titles (headings are left-aligned, per `SectionHeading`)
- Icon rows (no generic icon-set decoration)
- Round-avatar testimonial carousels
- New colors outside the token table above

## Placeholders

Generated by `scripts/gen-placeholders.mjs` into `public/placeholders/` (local SVGs only — no external image services). Regenerate with `npm run placeholders`. Every image path referenced from components must come from `site.ts` / `site.media`.

## Testing

Test every feature at 390px, 768px, and 1440px viewport widths before considering it done.

## Workflow

After each feature: run `npm run dev`, verify in the browser at the three breakpoints above, then `git commit`.
